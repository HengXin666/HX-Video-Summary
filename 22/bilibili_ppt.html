项目总览

一档每日AI资讯早报的诞生

在速度、成本和能力的三角约束下，采用AI处理 + 人工把关的混合工作流，而非完全自主Agent架构

速度优先

每日定时发布，覆盖前一天全球AI领域重要动态，追求时效性

质量把控

AI初筛+人工精筛双重过滤，保留最官方、最准确、最早的信源

核心理念：整个项目"全都是AI浇筑的始山"——以AI为效率引擎驱动规模化信息处理，同时在关键节点保留人工判断，确保内容质量与可信度。

第一环节

信息采集：多渠道汇聚AI前沿资讯

RSS主力渠道 + X平台实时追踪 + 手动补充 + 社区反馈，构建全方位信息雷达网

RSS订阅源

Linux Store、Reddit等原生支持RSS；通过RSS Hub桥接不支持RSS的主流网站。信息已结构化、正文保留样式，便于AI后续处理。

X 平台

全球AI信息的前沿阵地。几乎所有国内外AI公司及大企业AI部门都在X设立官方账号发布信息，是不可或缺的实时信源。

手动采集

使用Obsidian Web Clipper浏览器插件，手动提取页面元素并转化为带元信息的Markdown，再通过AI编写的自定义插件发送至后台。

社区反馈

节目积累了一批紧跟AI热点的观众，评论区、私信和交流群成为获取最新资讯的重要补充渠道。

信息源广度是核心竞争力：早报每天资讯丰富的关键，在于覆盖了从RSS到社交媒体、从自动化到人工的完整信息采集矩阵。
第二环节

信息筛选：AI四步并行 + 人工精筛

采集的信息先由AI初筛（剔除无关或低价值内容），随后启动四项同步任务

01

摘要生成

为每条信息制作摘要，辅助后续筛选和快速浏览

02

关键词提取

提取关键词用于信息分类和归档，构建结构化知识库

03

去重过滤

与上一期早报及72小时内进入初筛的内容比对，排除重复信息

04

AI 打分

对信息进行质量评分，低分直接排除，高分作为人工筛选参考

关键节点——人工精筛：AI处理完成后，人工只保留最官方、最准确或最早的信源，并补充更多官方信息。这一环节是保障内容质量的生命线。
第三环节

内容生成与人工校对

各分类下的信息合并后作为上下文发送给AI，生成标题和正文，人工校对后配备链接和媒体素材

生成流水线

分类信息合并 AI生成标题+正文 人工校对审核 配备媒体素材

文字版处理

AI使用Markdown格式优化排版——加粗、行内代码块、表格均由AI决定和修改。主标题、目录和每条资讯的摘要也在该环节生成。

视频版处理

AI根据正文生成口播稿（按事件分段），再按标点拆分短句，每个短句作为一次TTS请求，通过音频时长确定时间轴。

最终产出：每条资讯都配备好标题、正文、来源链接和媒体资源，形成可直接分发的完整内容包。

技术底座

模型选型与推理平台

文本生成和语音合成均在JMC Cloud推理引擎平台完成，在效果、成本和速度间取得最佳平衡

文本模型

  • Qwen3-Next-80B-A3B-Instruct — 主力文本生成与处理
  • 摘要、打分、去重等任务分布式调用不同模型
  • 整体权衡速度、成本与效果

语音模型 (TTS)

  • MiniMax speech-02 HD — 此前主力，Podcast Girl音色
  • speech-2.6-turbo — 因成本优化切换
  • 平台同时提供ElevenLabs等顶尖模型

JMC Cloud 平台优势：全球仅六家NVIDIA Reference Platform Partner之一，模型推理速度极快。提供文本、语音、图像、视频等各类顶级模型一键调用，对开发者和内容创作者非常友好。

成本敏感场景 → Turbo模型  |  质量优先场景 → HD模型

技术深潜

视频制作技术栈全解

画面 = HTML网页截图 + 声音 = TTS语音合成 + 剪辑 = FFmpeg全自动化

画面生成

HTML网页 → Selenium + Chrome DevTools Protocol 截图。未来若成本合适，可能切换为图像生成模型直接生成。

语音合成

AI生成口播稿 → 按事件分段 → 按标点拆分短句 → 每短句一次TTS API请求

时间轴编排

计算每个合成音频时长 → 确定整个视频时间轴 → 各事件区间显示对应画面 → 事件间插入过渡

字幕与合成

口播稿 → SRT字幕 → 过渡效果+音效+进度条 → FFmpeg合成最终视频

全流程自动化：有了时间轴，其他内容都一一确定——画面显示区间、字幕同步、过渡效果、进度条——统一通过FFmpeg一键合成。
轻量方案

不想那么复杂？简易替代方案

对于觉得上述流程过于复杂的创作者，可以利用现有工具的免费能力快速搭建

方案一：定时采集

  • 使用 Grok 或 智谱清言
  • 设定获取24小时内AI新闻的定时任务
  • AI在指定时间将信息投递到邮箱
  • 完全免费，无需部署

方案二：一键生成视频

  • 使用 NotebookLM 视频概览功能
  • 根据采集的资讯一键生成视频
  • 无需编写代码
  • 适合个人创作者快速起步

路线对比：轻量方案适合个人创作者快速起步，但灵活性和质量上限有限；完整方案适合追求内容品质和规模化的专业运营。两条路线可根据自身需求选择。

总结

核心洞察总结

洞察 01

AI + 人工 > 纯AI

在速度、成本和能力的三角约束下，AI负责效率和广度，人工负责准确性和质量把关。不必追求全自动化，在关键节点保留人工介入是保障内容可信度的核心策略。核查事件的真实性与准确性、修补AI幻觉、补充官方信息——这些"一点点人工"是品质的分水岭。

洞察 02

信息源广度决定内容厚度

RSS的结构化优势、X平台的实时性、社区的互动反馈——多渠道信息采集矩阵是早报资讯丰富的根基。不是依赖单一信息源，而是构建一张覆盖全球AI动态的信息雷达网。

洞察 03

平台特性驱动分发策略

同一内容在不同平台需要差异化适配——知乎用Markdown的目录优势、YouTube用5000字符简介+外挂字幕、公众号需HTML转码——理解每个平台的约束和优势，才能最大化传播效果。

洞察 04

工具链整合是单人团队的核心竞争力

RSS Hub + LLM + TTS API + Selenium截图 + FFmpeg合成——通过巧妙整合成熟工具链，一个人也能持续产出高质量的每日内容。关键在于"搭积木"而非"造轮子"。

日后奋斗方向

从一档AI早报到终身事业的成长路径

以技术入行打基础

深耕AI工作流自动化——RSS解析、NLP处理、TTS合成、视频生成——以技术能力作为内容创作的护城河，持续优化效率和质量

AI行业日新月异——新模型、新平台、新范式层出不穷。保持敏锐，快速适应：模型切换、平台迁移、技术栈升级都要走在变化前面

不躺平 持续拼

从每日早报到周报月报，从文字版到视频版，从6个平台到更多渠道——不断拓展内容形态和覆盖面，以持续的投入和迭代建立长期价值

无论你是内容创作者、开发者还是AI爱好者——
