Line Program = 指令地址到源代码行列的映射矩阵，二进制存储为状态机
DWARF 核心价值： 调试断点（行绑定）· 性能分析（perf 符号解析）· Crash dump 分析（macOS symbolification）· 程序静态分析工具。DWARF 不依赖运行时可执行文件，可剥离为独立 debug 文件。

内联展开处理
DW_TAG_inlined_subroutine
+ DW_AT_ranges 支持多内联代码段
 工具: pyelftools (Python)
 工具: llvm-dwarfdump
 注意: 不推荐 GNU 版本
工具化要点： 构建 parent 指针回溯是性能瓶颈（DIE 数量庞大），但可预处理好目标 DIE。不同 ELF 文件间天然支持多进程并行处理（Python 中需注意 GIL）。编译器 quirks（如 Clang tail-merge / vtable-hoist）会导致控制流与 DWARF 不对应。
