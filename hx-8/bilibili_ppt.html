三大核心理念
人人对齐

多 Agent 质量闭环
先人人对齐
统一团队对 AI 工具的认知与使用方式。明确"怎么做、用什么工具、如何拼装成完整规范"。先理解 WHY，再掌握 HOW，否则"形似神不似"。
规范适合 AI 执行
AI 比人类更擅长严格遵守规范。每写一行代码自动检查合规性。人难 100% 遵守的规范，正是 AI 的最佳用武之地——约束即质量。
多 Agent 协作保障
不追求单一 Agent 100 分。通过"写 + 审 + 验"多 Agent 组合：一个 Agent 犯错，审查 Agent 能发现，验证 Agent 兜底，形成有限状态闭环。
美团团队的核心洞察："决定系统走向的不是谁写得更快，而是约束 AI 的能力"。这三个理念共同构成了 AI 编码时代的质量三角——对齐共识 × 规范约束 × 多Agent验证。
约束 AI 的能力 = 系统的质量上限

实践四 代码质量保障体系
AI + 人工协同，多 Agent 对抗审查
AI + 人工协同 Review
AI 解决规范类问题（SQL/DB/代码/前端规范）。人负责技术方案评审（架构划分、接口设计、功能符合预期）。
Pre-PR 审查机制
提交前调用 Review Agent 自动审查。生成 PR 报告：改动范围、影响面、风险点。人主动触发 AI 审查。
多模型对抗审查
Claude Code 审查 CodeBuddy 生成的代码，互为校验。如果两个 Agent 都犯错 → 反思规范本身是否有问题。
关键认知：Completion Gate 机制
允许一个 Agent 只做到 80-90 分——关键是每个 Stage 都有审查门禁。写完一个状态 → Agent 验证 → 通过才进入下一阶段 → 不通过则打回重改。这本质上是分布式系统 "Tolerance" 的思路。
AI 生成 Agent 审查 通过/打回 提交
测试用例是 AI 自我学习的基石——AI 自我验证 → AI 自我学习 → 持续产出高质量代码
实践五 模型策略
高配审查 + 低配执行 = 质量·速度·成本 三角平衡
高配模型
审查 + 设计
陪你讨论方案、详细设计
Debug 分析、变更影响评估
头脑风暴，确认想法对错
VS
低配模型
执行 + 生成
按详细设计照做，不需发散
约束已到位，自由空间有限
速度快 + 成本低
先保证质量 再提升速度 最后优化成本
为什么低配模型能执行？因为人的详细设计已经把约束给到位了——代码 Demo、数据结构、函数调用方式都已明确。Agent 不需要"发散"，只需要"照做"。这也是约束力量的直接体现。
执行：低配模型 · 快 + 省 审查：高配模型 · 智 + 准 平衡：质量 → 速度 → 成本

审慎思考 人与 AI 的高效协作方式
文档写到 每个 Part · 每个 Model
没有 AI 的时代
人与人沟通有容忍度。方案不写细，靠默契、习惯、记忆补全。研发文档"差不多能看懂就行"。
AI 时代的要求
人与 AI 没有"容忍度"。约束越清晰 → AI 越不会自由发散 → 产出质量越高。详细设计需涵盖代码 Demo、数据结构、函数调用方式。
核心协作公式
人把方案写细（每个 Part/Model/接口）→ Agent 按方案执行（无自由发散空间）→ AI 审查 Agent 验证规范合规 → 人最终确认方案符合预期。约束 = 输出质量的上限。
